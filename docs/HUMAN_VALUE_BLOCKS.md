# Human value blocks · Basic Orange Purse

This record recognizes Bob's (Bobby's) human attention and contribution to
Basic Orange Purse, including development with AI assistance.

**1 human value block (VB) ≈ 1 hour of human energy contributed.**
**1 VB = $100 of contributed value toward a voluntary gift-support baseline.**

These are retrospective scope estimates, not precise timesheets, invoices,
replacement-development prices, or debts owed by users. Gifts are voluntary.
AI execution is not a second person's contribution. Gifts received are not
recorded here, so this ledger does not calculate a remaining funding balance.

Method: [Human Value Blocks guide](https://github.com/mullojo/background-removal/blob/main/docs/HUMAN_VALUE_BLOCKS_GUIDE.md).
The published guide was fetched and compared with its local copy during review.
Cutout's allocations are examples only; none are transferred into this ledger.
